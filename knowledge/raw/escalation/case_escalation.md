# Case Escalation Procedure

## Purpose

Case escalation provides a structured process for moving significant investigations to higher-level review.

## Escalation Criteria

A case may be escalated when:

- Multiple suspicious indicators remain unresolved.
- The investigation identifies complex financial networks.
- Repeated suspicious activity is observed.
- Additional specialist review is required.
- Available evidence indicates elevated financial crime risk.

## Case Package

The case package should contain:

- Investigation summary
- Customer information
- Account information
- Relevant transactions
- Risk scores
- Behavioral analysis
- Network analysis
- Supporting evidence
- Investigator conclusion

## Documentation

Every escalation decision should include the reason for escalation and the evidence supporting the decision.
